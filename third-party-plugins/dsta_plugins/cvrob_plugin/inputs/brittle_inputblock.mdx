# My MDX Input Block

Developers should modify this file to build their own Input Block. For more information on AI Verify Input Blocks, please refer to the [AI Verify Input Block Page](https://gitlab.com/imda_dsl/t2po/ai-verify/ai-verify-portal/aiverify-plugin/-/blob/main/docs/InputBlock.md).

Below are some examples of how to create input blocks.

## Example HTML Form

<div style={{ display:"flex", flexDirection:"column", marginBottom:"10px" }}>
  <label htmlFor="fname">Augmentations Library:</label>
  <input type="text" id="aug_library" value={props.data["aug_library"]} onChange={(e)=>props.onChangeData("aug_library",e.target.value)} />

  <label htmlFor="fname">Augmentations Method:</label>
  <input type="text" id="aug_method" value={props.data["aug_method"]} onChange={(e)=>props.onChangeData("aug_method",e.target.value)} />

  <label htmlFor="fname">Severity Before (String):</label>
  <input type="text" id="severityb4" value={props.data["severityb4"]} onChange={(e)=>props.onChangeData("severityb4",e.target.value)} />

  <label htmlFor="fname">Severity After (String):</label>
  <input type="text" id="severityaf" value={props.data["severityaf"]} onChange={(e)=>props.onChangeData("severityaf",e.target.value)} />

  <label htmlFor="fname">Severity Before (Integer):</label>
  <input type="text" id="severityb4i" value={props.data["severityb4i"]} onChange={(e)=>props.onChangeData("severityb4i",e.target.value)} />

  <label htmlFor="fname">Severity After (Integer):</label>
  <input type="text" id="severityafi" value={props.data["severityafi"]} onChange={(e)=>props.onChangeData("severityafi",e.target.value)} />

</div>
## Example use of Decision Tree Component

The [AI Verify Shared Library DecisionTree](https://github.com/aiverify-foundation/aiverify/tree/main/aiverify-shared-library/packages/graph) allows user to build their own decision tree.

You can find an example of Decision Tree Input Block from the [Widgets for Fairness Metrics Toolbox](https://github.com/aiverify-foundation/aiverify/tree/main/stock-plugins/aiverify.stock.fairness-metrics-toolbox-widgets) plugin.
An example use of the **DecisionTree** component can be found in the implementation for the [AI Verify Fairness Tree](https://github.com/aiverify-foundation/aiverify/tree/main/stock-plugins/aiverify.stock.fairness-metrics-toolbox-widgets/-/blob/main/inputs/fairness-tree.mdx) is found under the *inputs* folder.
