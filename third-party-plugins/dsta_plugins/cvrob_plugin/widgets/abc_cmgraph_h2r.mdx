  <h3>Confusion Matrix Statistics</h3>

  <span>
    This widget shows how a model’s class-specific prediction behaviour changes as the
    severity of image perturbations increases.
  </span>

  <span>
    For each specified corruption algorithm and each class in the dataset, it tracks
    how the following metrics vary across severity levels:
  </span>

  <span>
    <ul>
      <li>True Positives (TP)</li>
      <li>True Negatives (TN)</li>
      <li>False Positives (FP)</li>
      <li>False Negatives (FN)</li>
    </ul>
  </span>
</div>

  <h4>
    <b>How to read?</b>
  </h4>

  <p>
    Each line graph corresponds to a selected corruption algorithm and a class in the dataset
    (e.g., class X). Each graph contains four lines representing:
  </p>

  <ul>
    <li>TP: number of samples where true label = class X and prediction = class X</li>
    <li>TN: number of samples where true label ≠ class X and prediction ≠ class X</li>
    <li>FP: number of samples where true label ≠ class X but prediction = class X</li>
    <li>FN: number of samples where true label = class X but prediction ≠ class X</li>
  </ul>

  <p>
    The y-axis represents the count of each metric for a given class, and the x-axis
    represents corruption severity.
  </p>

  <p>
    In general, good model performance is indicated by high TP and TN values, and low FP and FN values.
  </p>

  <p>
    As severity increases, model performance is expected to degrade, meaning TP and TN decrease
    while FP and FN increase.
  </p>

</div>

  width: "100%",

  <span>
    <b>Interpretation</b>
  </span>

  <span>
    A steeper decline in TP or increase in FN indicates reduced robustness under the given corruption.
    In such cases, retraining the model is recommended, along with:
  </span>

  <span>
    <ul>
      <li>Adding targeted augmentations of this corruption type during training</li>
      <li>Increasing diversity of training samples for affected classes</li>
      <li>Improving model architecture or regularization if degradation is widespread</li>
    </ul>
  </span>

  <span>
    A sharp increase in FP suggests the model is over-predicting a particular class under corruption.
    This may indicate:
  </span>

  <span>
    <ul>
      <li>Feature collapse (reliance on fragile or non-robust features)</li>
      <li>Visual similarity between corrupted class representations</li>
      <li>Class imbalance sensitivity</li>
    </ul>
  </span>

  <span>
    Recommended actions include:
  </span>

  <span>
    <ul>
      <li>Using contrastive learning to improve class separation</li>
      <li>Adding corrupted examples from other classes or reducing overrepresented corrupted samples</li>
      <li>Rebalancing class distribution in the dataset</li>
    </ul>
  </span>

  <span>
    If these metrics remain stable, the model can be considered robust to this corruption,
    and no further action is required.
  </span>

  <span>
    If trends move in the opposite direction (TP and TN increase while FP and FN decrease),
    this may indicate the model has overfitted to this specific corruption type during training.
    In this case, retraining with fewer augmentation samples of this corruption type is recommended.
  </span>
</div>
