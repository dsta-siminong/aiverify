  <p style={{ margin: "4px 0 0 0", padding: "10px 14px", backgroundColor: "#f0f4ff", borderLeft: "4px solid #6366f1", borderRadius: "4px" }}>
    <b>What is mAP?</b>
  </p>

  <p style={{ margin: "4px 0 0 0", padding: "10px 14px", backgroundColor: "#f0f4ff", borderLeft: "4px solid #6366f1", borderRadius: "4px" }}>
    Unlike image classification — where the model simply picks a class label and is
    either right or wrong — object detection requires the model to do two things
    simultaneously: identify <em>what</em> objects are present and <em>where</em> they
    are. A prediction only counts as correct if both are right. mAP captures this
    combined requirement in a single score.
  </p>

  <p style={{ margin: "4px 0 0 0", padding: "10px 14px", backgroundColor: "#f0f4ff", borderLeft: "4px solid #6366f1", borderRadius: "4px" }}>
    It builds up from two concepts:
  </p>

  <ul>
    <li>
      <b>IoU (Intersection over Union)</b> — a measure of how well a predicted bounding
      box overlaps with the ground truth box. It is the area of overlap divided by the
      total area covered by both boxes, giving a value between 0 and 1. A prediction
      is only considered a true detection if its IoU exceeds a set threshold
      (commonly 0.5, meaning at least 50% overlap). Below that threshold, even a
      correctly labelled box counts as a miss.
    </li>
    <li>
      <b>Average Precision (AP)</b> — for each object class, AP summarises how well
      the model finds all instances of that class (recall) while avoiding false alarms
      (precision), across all confidence thresholds. A perfect AP of 1.0 means the
      model found every object of that class with no false detections.
    </li>
  </ul>

  <p style={{ margin: "4px 0 0 0", padding: "10px 14px", backgroundColor: "#f0f4ff", borderLeft: "4px solid #6366f1", borderRadius: "4px" }}>
    <b>mAP</b> is then the mean of AP scores across all object classes. It can be
    thought of as the model's overall detection quality: how reliably it finds objects,
    places boxes around them accurately, and avoids false alarms — all at once.
    A higher mAP means the model is performing well across all of these dimensions.
  </p>
</div>
