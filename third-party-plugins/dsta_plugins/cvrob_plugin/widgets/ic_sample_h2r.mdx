  </span>

  <span>
    The predicted class of the image is also shown. A{" "}
    <span style={{ color: "red", fontWeight: "bold" }}>red</span> border appears

    <span style={{ color: "green", fontWeight: "bold" }}>green</span> border appears

  </span>

<InfoBox>
  <h4>
    <b>How to read?</b>
  </h4>

  <p>
    Each sequence of images corresponds to a specific corruption algorithm and is
    grouped by image path.
  </p>

  <p>
    Within each sequence, the image is shown across the full range of severity levels
    for that corruption. Alongside each image, the following details are provided:
  </p>

  <ul>
    <li>The severity level of the applied corruption</li>
    <li>The model’s predicted class for the corrupted image</li>
    <li>The ground truth class (actual label) of the image</li>
  </ul>
</InfoBox>
