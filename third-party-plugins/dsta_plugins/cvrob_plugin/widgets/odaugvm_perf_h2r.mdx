    <p style={{ margin: 0 }}>
      <b>What is mAP?</b>
    </p>

    <p style={{ margin: "8px 0 0 0" }}>
      In object detection, the model has to do two things at once: find the
      object and place the box in the right spot. A prediction only counts when
      the box overlaps the ground truth enough, which is measured by a metric called 
      Intersection over Union (IoU).
    </p>

    <p style={{ margin: "8px 0 0 0" }}>
      Average Precision (AP) summarizes how well the model performs for one class, balancing missed
      detections and false alarms. Mean Average Precision (mAP) is the average of AP across all classes,
      so it gives a single overall score for detection quality.
    </p>
  </div>
</InfoBox>
