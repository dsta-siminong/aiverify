odaugbc_algorithm.augmentations_class¶

class odaugbc_algorithm.augmentations_class.Augmentation(name, param_dict, aug_func)¶

Bases: object

Local-library augmentation backed by an albumentations/NRTK callable.

Holds the per-severity parameters and the corruption function selected for the callable’s library, and flags both whether the augmentation is deterministic and whether it is geometric (so its bounding boxes must be transformed alongside the image).

corr_func_sample(image, target, severity_idx)¶

Corrupt a single (image, target) sample at the given severity.

Photometric augmentations perturb only the image and pass the target (bounding boxes and labels) through unchanged. Geometric augmentations move the image and boxes together via an albumentations Compose with pascal_voc bbox params, returning a new target with the transformed boxes and their surviving labels.

Parameters:

  • image (np.ndarray) – HWC uint8 image to corrupt.

  • target (dict) – Detection target with "boxes" and "labels" tensors.

  • severity_idx (int | str) – Severity index or label.

Returns:

The corrupted image and its (possibly

updated) target.

Return type:

Tuple[np.ndarray, dict]

class odaugbc_algorithm.augmentations_class.AugmentationUrl(url, aug_name)¶

Bases: object

Remote augmentation backed by an HTTP augmentation service.

Queries the service for determinism, severities, and whether the augmentation is geometric on construction, and delegates corruption to the service (/corrupt for photometric, /corrupt_bbox for geometric).

corr_func_dataloader(testloader, severity_idx)¶

Wrap a loader so its samples are corrupted via the remote service.

Returns the original loader unchanged for None augmentation/severity; otherwise wraps the dataset in CorruptedDataset behind a new loader that mirrors the source loader’s batch size and collate function.

Parameters:

  • testloader (torch.utils.data.DataLoader) – Source loader of clean (image, target) samples.

  • severity_idx (int | str) – Severity index or label to apply.

Returns:

A loader yielding corrupted samples.

Return type:

torch.utils.data.DataLoader

corr_func_sample(image, target, severity_idx)¶

Corrupt a single (image, target) sample via the remote service.

Photometric augmentations send only the image to /corrupt and pass the target through unchanged. Geometric augmentations send the image, boxes, and labels to /corrupt_bbox so the server transforms them consistently, returning a new target built from the response.

Parameters:

  • image (np.ndarray) – HWC uint8 image to corrupt.

  • target (dict) – Detection target with "boxes" and "labels" tensors.

  • severity_idx (int | str) – Severity index or label.

Returns:

The corrupted image and its (possibly

updated) target.

Return type:

Tuple[np.ndarray, dict]

Raises:

requests.HTTPError – If a service request fails.

determine_deterministic()¶

Query the service for whether this augmentation is deterministic.

The None augmentation is deterministic without a request.

Returns:

True if the augmentation is deterministic.

Return type:

bool

Raises:

requests.HTTPError – If the service request fails.

determine_geometric()¶

Query the service for whether this augmentation is geometric.

Geometric augmentations transform bounding boxes alongside the image. The None augmentation is non-geometric without a request, and a service that does not expose the /geometric endpoint (e.g. a classification-only deployment) defaults to False rather than failing.

Returns:

True if the augmentation requires a bbox transform.

Return type:

bool

class odaugbc_algorithm.augmentations_class.CorruptedDataset(*args: Any, **kwargs: Any)¶

Bases: Dataset

Dataset wrapper that corrupts each source sample on access.

Delegates to an inner detection dataset and applies a per-sample corruption function at a fixed severity, converting to/from the HWC uint8 form the corruptor expects while carrying the detection target through.

odaugbc_algorithm.augmentations_class.check_module(module)¶

Select the corruption function matching an augmentation callable’s library.

Inspects the string form of module to route NRTK and albumentations callables to their respective corruption helpers.

Parameters:

module – The augmentation callable (or "None") to inspect.

Returns:

The matching corruption function, or the string "None".

Raises:

ValueError – If the library cannot be identified.

odaugbc_algorithm.augmentations_class.corrupt_func_album_reduced(images_np, aug_func, aug_params)¶

Apply an albumentations transform to a batch of images.

Composes aug_func with ToTensorV2 and applies it per image, advancing the random seed by the image index so each image is perturbed independently.

Parameters:

  • images_np (np.ndarray) – Batch of HWC images.

  • aug_func – Albumentations transform class to instantiate.

  • aug_params (dict) – Transform kwargs; "random_seed" is consumed here.

Returns:

Batch of corrupted HWC images.

Return type:

np.ndarray

odaugbc_algorithm.augmentations_class.corrupt_func_nrtk_reduced(images_np, aug_func, aug_params)¶

Apply an NRTK perturber to a batch of images, caching the perturber.

Splits out img_gsd/random_seed, injects seed when the perturber accepts it, and reuses a cached perturber keyed on the callable and params.

Parameters:

  • images_np (np.ndarray) – Batch of HWC images.

  • aug_func – NRTK perturber class to instantiate.

  • aug_params (dict) – Perturber kwargs, possibly with img_gsd/random_seed.

Returns:

Batch of perturbed images.

Return type:

np.ndarray

odaugbc_algorithm.augmentations_class.custom_parameter_change(aug_dict, aug_name, param_name, parameters_in_string)¶

Rebuild one augmentation in the dict using user-supplied parameter values.

Parses the value string, constructs a per-severity param_dict for the named parameter (with a special Erasing/scale case), and replaces the matching augmentation with a fresh Augmentation built from it.

Parameters:

  • aug_dict (dict) – Mapping of augmentation name to Augmentation instance.

  • aug_name (str) – Name of the augmentation to override.

  • param_name (str) – Name of the parameter to set.

  • parameters_in_string (str) – Comma-separated parameter values to apply.

Returns:

The updated augmentation dict (mutated in place).

Return type:

dict

odaugbc_algorithm.augmentations_class.get_augmentation_dict_album_header()¶

Returns:

Augmentation name -> {severity_label: (transform_class, params)}.

odaugbc_algorithm.augmentations_class.handle_url_algos(aug_dict, aug_algos)¶

Populate the URL-backed augmentation dict with remote augmentations.

When aug_algos is ["all"], the available augmentations are fetched from the service’s /health endpoint; each is added as an AugmentationUrl.

Parameters:

  • aug_dict (dict) – URL-backed augmentation dict containing a "url" entry.

  • aug_algos (list[str]) – Augmentation names to add, or ["all"].

Returns:

The updated augmentation dict (mutated in place).

Return type:

dict

Raises:

requests.HTTPError – If the /health request fails.
